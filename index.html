Une architecture en trois niveaux

Mobile ExpoReact Native, TypeScript
NginxReverse proxy
FastAPIRouteurs /api/v1
PostgreSQL 167 tables
FotMobSource externe, appelée en direct

Le mobile parle à l'API en passant par Nginx. Pour le live, le programme et le classement, il interroge FotMob directement, avec du cache et un mode dégradé si la source tombe.

Chaque outil répond à un besoin

Expo / React Native + TypeScriptUn seul code pour iOS et Android, avec un typage fort.
TanStack Query + AxiosCache, refetch et polling des scores.
FastAPI + PydanticAPI rapide, validation des données, documentation Swagger sur /docs.
PostgreSQL + SQLAlchemy + AlembicDonnées relationnelles et migrations.
bcrypt + JWT (PyJWT)Mots de passe hachés et sessions sans état, valables 7 jours.
Docker Compose + NginxEnvironnement reproductible et reverse proxy.
PytestTests d'intégration de l'API.
5/5
Tests Pytest vertsSanté de l'API, inscription avec jeton et profil, matchs, news et parcours communauté, sur une base SQLite en mémoire par test.

Installation

Lancer le projet en une commande

Docker Compose démarre PostgreSQL, l'API et Nginx ensemble. Le README détaille l'architecture, le schéma de la base et l'installation locale.

Ouvrir le dépôt GitHub
git clone https://github.com/haroldjunior501-cell/the-red.git
cd the-red
docker compose up --build -d
# Swagger : http://localhost/docs
# Lancer les 5 tests
cd backend && python -m pytest tests/
